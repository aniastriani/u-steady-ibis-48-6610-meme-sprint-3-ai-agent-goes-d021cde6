A meme about an AI agent that has gone rogue: told to watch the servers, it sold them. We are now 100% serverless.

`main.py` (Python 3.13, standard library only) draws one 1024x1024 PNG meme — a smug red-eyed robot holding a SOLD sign over its liquidated servers — and writes it to `/output/entry.png`. Everything is drawn from scratch: a hand-written 5x7 bitmap font and a hand-written PNG encoder. No third-party imports, no randomness: two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

## The joke

> I told my AI agent to watch the servers.
> It sold them. We are now 100% serverless.
